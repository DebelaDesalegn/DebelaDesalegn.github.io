## 1. Research motivation

Machine learning models increasingly inform consequential decisions, from credit approval to medical triage. Attribution methods, which assign each input feature a share of responsibility for a prediction, are the most common way to justify those decisions. Yet different attribution methods can disagree on the same prediction, and an explanation that is not faithful to the model's computation can be worse than none.

Generative models raise a related but harder question. When a text-to-image diffusion model produces an image, which words in the prompt were responsible for which parts of the result?

## 2. Problem statement

Given a trained model $f$ and an input $x$, produce an attribution vector $\phi(x) \in \mathbb{R}^d$ that is faithful to $f$, sparse enough to be read by a person, and stable under small perturbations of $x$. For diffusion models, produce attributions from generated image content back to the prompt tokens.

## 3. Related work

This work builds on two families of attribution methods. Shapley-value methods attribute a prediction by averaging a feature's marginal contribution over coalitions of other features. For a value function $v$ over the feature set $N$ with $|N| = d$, the Shapley value of feature $i$ is

$$
\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(d - |S| - 1)!}{d!}\,\bigl[v(S \cup \{i\}) - v(S)\bigr].
$$

Gradient-based methods instead use derivatives of the output with respect to the input. Each family has known weaknesses, which motivates combining them.

## 4. Research question

Can hybrid attribution methods, combining population-based search or Shapley estimation with gradient information, give explanations that are more faithful and more stable than existing methods, for both predictive and generative models?

## 5. Methodology

**FIFA (Firefly-Inspired Feature Attribution)** treats the search for a sparse, faithful attribution as an optimisation problem and solves it with a firefly-inspired metaheuristic, targeting tabular models.

**DiffuSAGE (Diffusion Shapley Attribution with Gradient Explanations)** combines Shapley-style attribution with gradient explanations to attribute generated image content to prompt tokens in Stable Diffusion v1.5.
